# 多宠物形象与人物角色素材设计

## 目标

在保留现有边牧形象的基础上，新增一个由用户提供照片衍生的 Q 版人物形象。用户可在右键菜单中选择形象，切换过程不重置当前动作、位置、尺寸、番茄钟、聊天或备忘录状态。

## 角色视觉设定

- 人物采用约 2.5 头身的完整全身比例，适合桌宠小尺寸显示和全部现有动作。
- 画风与现有边牧一致：精致 2D Q 版插画、深色手绘轮廓、柔和上色、大眼睛和清晰轮廓。
- 保留参考照片中的黑色中分长发、眉眼轮廓、柔和微笑和脸型特征，卡通化后仍可辨认。
- 保留灰色西装、白衬衫和黑灰格纹领带。胸前徽章简化为无文字的金蓝色装饰。
- 所有素材禁止文字、水印、地面、投影、光晕、动作线、漂浮装饰和额外道具。

## 素材规格

每个运行时帧为 `480 x 432` RGBA 透明 PNG，与当前边牧素材一致。人物在画布中完整显示且保留安全边距；同一动作组使用统一缩放、视觉中心和脚底基线，播放时不能出现尺寸跳变或上下抖动。

实际运行需要 29 张人物帧：

| 动作 | 帧数 | 人物表现 |
| --- | ---: | --- |
| `idle` | 4 | 呼吸、眨眼和轻微身体摆动 |
| `walk` | 4 | 向右行走循环，向左由现有水平翻转实现 |
| `run` | 4 | 向右快速跑步循环 |
| `jump` | 3 | 起跳、腾空、落地 |
| `sit` | 2 | 自然坐姿和轻微呼吸 |
| `lying` | 1 | 无家具的伏地或蜷卧姿势 |
| `sleep` | 1 | 闭眼睡眠姿势 |
| `wag` | 4 | 人物挥手，替代摇尾巴 |
| `tilt` | 2 | 歪头和表情变化 |
| `sniff` | 2 | 好奇地左右观察 |
| `scratch` | 2 | 挠头动作 |

`happy` 继续复用 `tilt` 帧，`drag` 继续复用第一张 `tilt` 帧，因此不额外生成。现有未被运行时使用的 `walk_front` 和 `walk_back` 不要求人物版本。

## 素材生产流程

1. 使用用户确认的参考照片 `/Users/asura/Downloads/人物.png` 生成一张纯色绿幕背景的正面全身角色基准图，先确认相似度、比例、服装和画风。生成阶段需要将参考照片发送给所选图片生成服务。
2. 以确认后的基准图作为身份参考，按动作组分别生成帧条。每组都重复锁定发型、脸型、服装、徽章、比例和色板。
3. 本地移除绿幕和绿色边缘，将动作条拆分为独立帧，并统一到 `480 x 432` 透明画布。
4. 对每组检查裁切、透明边缘、连通性、视觉中心、脚底基线和帧间比例。
5. 输出静态联系表和 GIF 循环供视觉验收；只返工失败的动作组。

如果默认图片生成能力无法稳定保留人物身份，则停止批量生成，交付角色基准图、逐动作提示词、负面约束和帧验收标准，供用户在其他模型中生成。外部生成结果仍进入相同的本地拆帧和校准流程。

## 运行时架构

新增独立角色注册表，角色配置至少包含：

- 稳定的角色 id 和菜单显示名；
- 各动画状态对应的帧 URL 与帧率；
- 各姿势用于气泡和附加面板定位的视觉边界；
- 人物与边牧各自的互动菜单文案。

现有状态机继续管理 `state`、`frameIdx`、移动、番茄钟和拖拽。渲染时只从当前角色配置中解析对应状态帧，角色切换不创建新的状态机。

资源目录调整为：

```text
src/assets/characters/
  border-collie/
  person/
```

边牧现有素材移动到自己的目录；人物目录只包含运行时需要的 29 张帧。构建时通过 Vite 静态资源导入获取 URL。

## 切换交互

- 右键菜单新增“宠物形象”项目，点击后在当前菜单内部展开选择区域。
- 选择区域显示角色缩略图、名称和当前选中勾号，首期提供“边牧”和“人物”。
- 不使用独立悬浮子菜单，继续沿用已适配 Windows DPI 和屏幕边缘的菜单内展开方式。
- 两套运行时素材在启动时预加载并解码。用户选择后保留当前动画状态，并立即显示新角色的对应帧。
- 选择写入 `localStorage`，下次启动恢复。成品应用运行时不包含或上传原始照片，也不上传角色选择；这不包括开发期间由图片生成服务处理参考照片的过程。
- 人物形象下，“摇尾巴、嗅一嗅、挠痒痒”分别显示为“挥挥手、好奇看看、挠挠头”。边牧文案保持不变。

## 异常处理

- 角色在必需帧未全部成功加载前不可选择，并通过宠物气泡提示素材加载失败。
- 已选择角色如果在运行时发生单帧加载错误，立即使用边牧相同状态的对应帧，避免宠物消失。
- 本地保存了未知或已删除的角色 id 时，启动回退到边牧并修正保存值。
- 角色切换期间不改变窗口位置、窗口尺寸、当前动作、移动方向或功能面板状态。

## 验证

- 自动检查两套角色配置的状态集合、帧数、文件存在性、尺寸和 alpha 通道。
- 单元测试覆盖角色 id 恢复、未知 id 回退、当前状态帧解析、人物文案映射和切换持久化。
- 静态联系表与 GIF 验证人物身份一致、动作循环连续、无裁切、无背景残留和无尺寸跳变。
- 在 macOS 和 Windows `100% / 125% / 150%` 缩放下手工验证菜单展开、角色切换、拖拽、气泡、番茄钟键盘和备忘录提示位置。

## 不在本次范围

- 在线下载角色、角色商城或用户上传自定义素材；
- 角色云端同步；
- 重新设计动画状态机；
- 为当前未使用的正面/背面行走素材生成对应人物帧；
- 2D 骨骼或 3D 模型系统。
